Step 1

반복 업무 1개 고르기

반복되고, 자료가 남아 있고, 결과물이 명확한 업무 1개를 고릅니다.

04

작성 질문

Q1. 내가 자주 반복하는 업무는?
Q2. 가장 시간이 많이 걸리는 지점은?
Q3. 반복될 때 생기는 문제는?
Q4. AI 초안을 사람이 검토 가능한가?

멘토 질문

이 업무는 몇 번 반복되나요?
자료가 이미 존재하나요?
결과물이 명확한가요?
AI 초안을 사람이 검토할 수 있나요?
TIP
크게 잡으면 실패팀 전체보다 반복 업무 1개. 회의록 정리, 주간보고 취합, 문의 응대 초안처럼 작고 반복되는 업무부터 시작합니다.
Step 2

Input / Check / Output 뽑기

폴더를 만들기 전에 업무를 4개 요소로 나눕니다.

05
구분질문내 업무 기준 작성
InputAI가 읽어야 할 자료는?
CheckAI가 따라야 할 기준은?
OutputAI가 만들어야 할 결과물은?
Human Check사람이 확인할 부분은?
TIP
도구보다 문제시간이 오래 걸리는 지점, 기준이 흔들리는 지점, 같은 설명을 반복하는 지점이 좋은 후보입니다.

예시

Input 회의 녹취록, 회의 메모, 지난 회의록
Check 회의록 양식, 액션아이템 기준, 외부 공유 금지 기준
Output 회의록 초안, 담당자/기한 표, 공유 메일 초안
Human Check 결정사항 사실 여부, 담당자 누락, 민감정보 포함 여부

Step 4

CLAUDE.md 초안 만들기

프로젝트 전체의 역할, 원칙, 금지사항, 출력 방식을 고정합니다.

07
# [프로젝트 이름]

## 역할
너는 [업무명]을 보조하는 AI 업무 동료다.

## 업무 목표
이 프로젝트의 목표는 [반복 업무의 비효율]을 줄이고,
[만들어야 할 결과물]을 일관된 기준으로 생성하는 것이다.

## 기본 원칙
- 원본 자료에 없는 내용은 단정하지 않는다.
- 결과물은 초안이며, 최종 판단은 사람이 한다.
- 민감정보는 임의로 노출하지 않는다.

## 사람 검수 지점
- 사실관계
- 수치
- 개인정보/민감정보
- 외부 발송 여부

멘토 질문

이 업무를 신입에게 맡긴다면 반드시 알려줄 기준은?
결과물이 좋다/나쁘다를 판단하는 기준은?
AI가 절대 하면 안 되는 행동은?
최종 판단은 누가 해야 하나요?
TIP
CLAUDE.md는 직무기술서AI가 프로젝트 안에서 같은 기준으로 일할 수 있도록 역할과 업무 원칙을 명시합니다.

Step 7

command 파일 초안 만들기

command는 긴 프롬프트가 아니라 반복 업무의 실행 절차입니다.

10
# [skill-name]

## 설명
[이 Skill이 처리하는 반복 업무를 한 줄로 설명합니다.]

## 입력
- data/[원본 자료]
- reference/[기준 문서]

## 처리 단계
1. 원본 자료를 읽는다.
2. 핵심 내용을 추출한다.
3. 기준 문서에 맞춰 분류한다.
4. 출력 형식에 맞춰 초안을 작성한다.
5. 사람 검수 항목을 별도로 표시한다.

## 출력
- output/[결과물 폴더]

## 사람 확인 필요
- 사실관계
- 수치
- 개인정보/민감정보
- 최종 발송 여부
TIP
command는 업무 레시피어떤 자료를 읽고, 어떤 기준으로 판단하고, 어떤 순서로 처리하고, 어디에 남길지 적습니다.
Mentoring

멘토 피드백 체크리스트

멘토는 폴더가 실제 업무 실행으로 이어지는지 확인합니다.

11
영역체크포인트
업무 범위업무가 1개로 좁혀져 있는가?
폴더 구조data / reference / output / commands가 구분되어 있는가?
CLAUDE.mdAI 역할, 목표, 금지사항, 사람 검수 지점이 있는가?
Skill입력 / 처리 단계 / 출력이 연결되는가?
실무 적용성실제 자료를 넣으면 바로 테스트할 수 있는가?
TIP
좋은 구조는 바로 테스트폴더명과 Skill 이름이 그럴듯해도 실제 자료를 넣었을 때 무엇을 해야 할지 모르면 아직 구조가 부족한 상태입니다.

# 평가서통합

## 설명
면접관별 평가서를 표준화하고 후보자별 통합 카드 초안을 작성한다.

## 입력
- data/평가서원본/
- data/표준스키마.md
- reference/평가항목기준.md

## 처리 단계
1. 면접관별 평가서를 읽는다.
2. 후보자ID 기준으로 평가서를 묶는다.
3. 점수와 코멘트를 표준 스키마에 맞춰 정리한다.
4. 후보자별 강점 3개, 우려 3개, 총평 초안을 작성한다.
5. 편향 표현과 누락 항목을 체크리스트로 표시한다.
